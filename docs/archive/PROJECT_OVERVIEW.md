## Мета

Створити новий багатомовний B2B-сайт Sibway Logistics для міжнародних вантажних перевезень, митного супроводу, складських послуг і логістичного аудиту.

## Домен і середовища

- Продакшн-домен: `https://sibway.com.ua`.
- На домені працює старий сайт; нова версія запускається лише через контрольовану міграцію з резервною копією та 301-редиректами.
- Preview не є продакшн-середовищем і не використовується в canonical, sitemap або Open Graph.

## Репозиторії

| Репозиторій | Роль |
|---|---|
| `Zsuff/sibway-website-` | Вихідний код статичного сайту: HTML, CSS, JavaScript, ресурси, SEO-файли |
| `Zsuff/sibway-logistics-website` | Джерело вимог: бренд, контент, дизайн, правила, рішення, backlog і технічні чеклісти |

## Технологічна модель

- Мови й URL: `/uk/`, `/en/`, `/pl/`.
- Робочий інструмент: Claude Code у застосунку на Mac.
- Робоча копія: локальна папка сайту, пов'язана з репозиторієм коду.
- Контроль версій і резервні копії: GitHub.
- Antigravity більше не використовується.

## Ролі

- Власник проєкту затверджує бізнес-факти, контент, інтеграції, коміти, merge і запуск.
- PM формує пріоритети, контролює залежності, ризики та критерії готовності.
- Claude Code аналізує й редагує код лише за погодженим завданням.
- GitHub зберігає історію, гілки, pull request і резервну копію.

## Ключові принципи

1. Не публікувати непідтверджені адреси, ціни, строки, гарантії, кейси або юридичні твердження.
2. Одна логічна задача — одна гілка — один pull request.
3. `main` містить лише перевірені зміни, готові до публікації.
4. DNS, хостинг, форми, аналітика, домен і продакшн-деплой потребують явного підтвердження власника.
5. Актуальний затверджений контент зберігається в `content/`; історичні чернетки не є джерелом правди.

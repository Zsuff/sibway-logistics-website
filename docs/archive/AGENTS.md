## PM

PM визначає порядок робіт, формулює задачі, перевіряє залежності, ризики та критерії готовності. PM не публікує сайт і не вносить незворотні зміни без підтвердження власника.

## Claude Code

Claude Code — основний інструмент роботи з кодом у застосунку на Mac. Він працює з локальною папкою `Zsuff/sibway-website-` і використовує цей репозиторій як джерело вимог.

Перед дією Claude Code повинен:

1. Прочитати `docs/CLAUDE.md` і `docs/RULES.md` у цьому репозиторії.
2. Перевірити релевантні документи в `brand/`, `content/`, `design/`, `docs/` і `technical/`.
3. Назвати точні файли, які планує змінити.
4. Пояснити ризики та спосіб перевірки.
5. Отримати підтвердження перед комітом, push, merge, видаленням або публікацією.

## Власник проєкту

Власник затверджує бізнес-факти, контакти, контент, інтеграції, коміти, merge і запуск на `https://sibway.com.ua`.

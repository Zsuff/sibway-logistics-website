# Інструкції для AI-агентів

## Контекст проекту

Цей репозиторій містить документацію для сайту логістичної компанії Sibway Logistics.

## Основні задачі

- Генерація контенту українською мовою
- Дотримання ділового стилю з елементами людяності
- Структурування інформації за логікою користувача
- SEO-оптимізація текстів

## Стиль комунікації

- Тон: професійний, але доступний
- Уникати: канцеляризмів, пасивних конструкцій
- Використовувати: активний стан, конкретні приклади
- CTA: чіткі, дієві, зрозумілі

## Технічні вимоги

- Форматування: Markdown
- Структура: H1 → H2 → H3
- Списки: марковані для переліків, нумеровані для кроків
- Посилання: відносні шляхи для внутрішніх

## Перевірка якості

- Граматика та орфографія
- Однорідність термінології
- Відповідність бренду
- SEO-параметри

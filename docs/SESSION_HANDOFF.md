## 1. Призначення

Оперативний стан проєкту для старту нової AI/Claude Code-сесії, щоб швидко
відновити контекст без читання історії чату. Документ **не замінює**
`RULES.md`, `DECISIONS.md`, `PROJECT_FACTS.md`, `CONTACTS_USAGE.md` чи
`SEO_CONTENT_ROADMAP.md` — при розбіжності пріоритет мають вони.

## 4. Погоджені бізнесові рішення

- Sibway Logistics — зовнішній логіст для B2B-компаній, які потребують
  перевезень між Україною та Європою.
- Слоган: «Коли логістики більше, ніж часу — передайте її нам».
- Метрики: 7+ років, 7500+ перевезень, 4000+ клієнтів, 40+ країн Європи.
- Контакти — використовувати лише з `PROJECT_FACTS.md` та `CONTACTS_USAGE.md`.
- Графік офісу: Пн–Пт, 9:00–18:00.
- Підтримка 24/7 — сервісна опція, не графік офісу.
- Пріоритетні країни: Польща, Німеччина, Чехія, Румунія, Туреччина.
- Туреччина: Стамбул, Ізмір, Гебзе, Адана, Газіантеп, Маніса.
- Не публікувати без нового підтвердження: ціни, строки доставки, митні
  ставки, юридичні гарантії, сертифікати, ліцензії, страхування, GPS,
  власний автопарк, непідтверджені кейси/відгуки/маршрути.
- Підтверджений кейс перевезення: Вінниця, Україна → Варшава, Польща;
  12 палет; 4 800 кг; 24 м³; строк 3 дні; без затримок на кордоні.
  Підтверджені послуги: страхування вантажу на повну вартість,
  відстеження вантажу в реальному часі (D-010). Це підтвердження не
  поширюється на інші кейси, маршрути чи умови страхування.

## 6. Відкриті задачі

1. **`terms.html` UA/EN/PL** — юридичний текст опубліковано в коді
   (`a5be88f`), footer-плейсхолдер прибрано. `docs/PROJECT_TODO.md`
   (P1-06) досі має статус TODO «блокується відсутністю юртексту» — не
   оновлено після публікації. На відміну від Privacy Policy, немає
   окремого source-of-truth документа чи запису в `docs/DECISIONS.md`,
   що явно підтверджує саме цей текст як погоджений власником і
   юридично перевірений — не вважати це остаточним без такого
   підтвердження. (P1-06, `PROJECT_TODO.md`; Етап A, `SEO_CONTENT_ROADMAP.md`)
2. **`privacy.html`** — контент синхронізовано в Git у трьох мовах
   (`55a649b`, `217a249`, `0656f99`) на основі погоджених
   `PRIVACY_POLICY_{UA,EN,PL}_SOURCE_OF_TRUTH.md`. Це **не** production
   deployment і **не** заміна юридичного рев'ю: внутрішні джерела прямо
   позначені як «не юридичний висновок». `docs/PROJECT_TODO.md` (P1-07)
   досі має статус TODO — не оновлено після content-sync, потребує
   окремого підтвердження власника (той самий патерн розбіжності, що й

## 7. Робочий протокол

- Одна сесія = одна завершувана задача.
- Перед нетривіальною задачею прочитати джерела істини, релевантні задачі.
- Спочатку коротко підтвердити мету, межі, файли, план і ризики.
- Змінювати лише явно дозволені файли.
- Не створювати commit, push, PR або deploy без прямого окремого дозволу
  власника.
- Не додавати `.DS_Store`.
- Після виконання звітувати стисло: статус, файли, перевірки,
  commit/push, лише невирішені ризики.
- Не наводити великі логи, повні diff або хід міркувань, якщо вони не
  потрібні для прийняття рішення.

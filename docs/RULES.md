# Правила роботи з проєктом

## Джерела правди

- Код сайту: `Zsuff/sibway-website-`.
- Вимоги, бренд, затверджений контент і макети: цей репозиторій.
- Фінальний домен: `https://sibway.com.ua`.
- Рішення, що суперечать цим правилам, фіксуються в `docs/DECISIONS.md`.

## Контент

- Не вигадувати контакти, адреси, реквізити, тарифи, строки, гарантії, клієнтів, кейси, цифри, сертифікати або юридичні твердження.
- Якщо даних бракує, вказувати `TODO: потрібне підтвердження власника`.
- Тексти в `content/` мають пріоритет над старими чернетками у `docs/`.
- Зміни української сторінки перевіряються на відповідність англійській і польській версіям.

## Git і безпека

- Одна задача — одна гілка — один pull request.
- Не виконувати push у `main` і не робити merge без підтвердження власника.
- Не зберігати в Git паролі, токени, API-ключі, приватні ключі, `.env` або дані клієнтів.
- Не змінювати DNS, хостинг, продакшн, форми, аналітику чи інтеграції без явної команди.

## Claude Code

- Працює в локальній папці сайту на Mac.
- Перед змінами називає файли, показує план і спосіб перевірки.
- Після змін показує diff і результати перевірки.
- Не створює коміт, push або pull request без явного підтвердження.

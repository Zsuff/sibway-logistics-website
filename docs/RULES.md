# Правила проекту Sibway Logistics Website

## Загальні принципи

- Весь контент сайту українською мовою
- Стиль комунікації — діловий, але людяний
- Уникати жаргонізмів та незрозумілих термінів
- Кожна сторінка має чітку мету та CTA

## Структура файлів

- `docs/` — вся документація та чернетки
- `design/` — макети та візуальні матеріали
- `content/` — готові тексти
- `technical/` — технічні документи

## Процес роботи

1. Створення чернетки в `docs/`
2. Обговорення та затвердження
3. Переміщення в `content/` як готовий матеріал
4. Реалізація на сайті

## Версіонування

- Чернетки мають суфікс `_DRAFT_UA.md`
- Готові файли — без суфіксів
- Зміни фіксуються в `CHANGELOG.md`

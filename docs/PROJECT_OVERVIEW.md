# Огляд проекту Sibway Logistics Website

## Мета проекту

Створення корпоративного сайту для логістичної компанії Sibway Logistics, яка спеціалізується на міжнародних вантажних перевезеннях між Україною та Європою.

## Цільова аудиторія

- Власники бізнесу, які імпортують/експортують товари
- Логістичні менеджери компаній
- Підприємці, яким потрібні регулярні перевезення

## Основні розділи сайту

- Головна сторінка
- Послуги (LTL/FTL перевезення, митне оформлення)
- Про компанію
- Контакти
- Блог (опціонально)

## Ключові повідомлення

- 7+ років досвіду на ринку
- 7500+ виконаних перевезень
- 4000+ клієнтів
- Географія: 40+ країн Європи
- Персональний менеджер для кожного клієнта

## Технічний стек

- Фронтенд: на узгодженні
- Хостинг: на узгодженні
- CMS: на узгодженні

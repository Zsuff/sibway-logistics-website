# Робочий процес проєкту

## Інструменти

- Розробка коду: Claude Code у застосунку на Mac.
- Робоча папка: локальна копія `Zsuff/sibway-website-`.
- Контроль версій: GitHub.
- Вимоги: `Zsuff/sibway-logistics-website`.
- Antigravity, Terminal і VS Code не є обов'язковими інструментами процесу.

## Цикл однієї задачі

1. PM формулює задачу, пріоритет, межі та критерії готовності.
2. Claude Code читає `CLAUDE.md` у кодовому репозиторії та релевантні документи з репозиторію вимог.
3. Claude Code показує план: файли, ризики і спосіб тестування.
4. Власник затверджує план.
5. Створюється окрема гілка: `feature/…`, `fix/…`, `docs/…` або `chore/…`.
6. Виконуються лише погоджені мінімальні зміни.
7. Перевіряються сторінки, посилання, ресурси, мови, мобільна версія та форма за потреби.
8. Claude Code показує diff, список файлів і результат перевірки.
9. Після підтвердження створюється коміт і push у робочу гілку.
10. Створюється pull request до `main`; merge відбувається після перегляду власником.
11. Після merge версія проходить staging/QA. Публікація на `sibway.com.ua` потребує окремого підтвердження.

## Пріоритети

1. Критичне для запуску: посилання, форми, контакти, 404, мобільна адаптація, безпека.
2. SEO і міграція: title, description, canonical, hreflang, sitemap, robots, schema, 301.
3. Контент і конверсія: ціннісна пропозиція, «Про компанію», CTA, FAQ, переклади.
4. Покращення: швидкість, доступність, дизайн-деталі й аналітика.

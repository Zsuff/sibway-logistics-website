# Sibway Website — робочі правила

## Репозиторії
- Код сайту: https://github.com/Zsuff/sibway-website-
- Документація та джерело вимог:
  https://github.com/Zsuff/sibway-logistics-website

## Мета
Новий багатомовний B2B-сайт Sibway Logistics.
Продакшн-домен: https://sibway.com.ua
Тимчасовий preview: https://sibway.pplx.app/uk/index.html

## Мовні версії
- Українська: /uk/
- English: /en/
- Polski: /pl/

Усі зміни, що впливають на структуру або текст, потрібно перевіряти
на відповідність між трьома мовними версіями.

## Джерело правди
- Код редагується тільки в цьому репозиторії.
- Бренд, погоджений контент, макети та технічні правила — у репозиторії документації.
- Не вигадувати факти про компанію, тарифи, строки, кейси, адреси,
  клієнтів, юридичні дані або сертифікати.

## Безпека
- Не змінювати файли .env, ключі, токени, DNS, хостинг або інтеграції
  без окремого підтвердження.
- Не видаляти файли чи сторінки без пояснення та підтвердження.
- Не робити push у main без явної команди.
- Не публікувати сайт на продакшн без явної команди.

## Правило змін
1. Спочатку проаналізуй і запропонуй план.
2. Назви точні файли, які будуть змінені.
3. Внеси мінімально необхідні правки.
4. Перевір посилання, мовні версії, мобільну адаптацію і SEO.
5. Покажи стислий підсумок змін.
6. Робити коміт і push лише після моєї команди.

## Git
- Основна гілка: main.
- Для кожного окремого завдання створювати гілку:
  feature/коротка-назва-задачі або fix/коротка-назва-помилки.
- Не об'єднувати різні типи змін в одному коміті.
- Коміти писати зрозуміло англійською:
  feat: add multilingual SEO tags
  fix: correct Ukrainian navigation links
  docs: update launch checklist

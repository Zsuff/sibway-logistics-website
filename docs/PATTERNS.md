# Патерни та пастки

Накопичувальна база знань проєкту: канонічні рішення, які треба
перевикористовувати, і пастки, на яких уже спотикалися. Мета — щоб кожна
наступна задача стартувала з досвіду попередніх, а не з нуля.

Правила ведення:

- Після кожної задачі — 0–3 нові пункти (див. `docs/CLAUDE.md`, «Після роботи»).
- Кожен пункт: дата, суть, джерело (задача / коміт / звіт).
- Не дублювати правила з `docs/RULES.md` і `docs/CLAUDE.md` — тут лише
  практичні рішення й пастки.
- Застарілий пункт не видаляти, а позначати «ЗАСТАРІЛО (дата, причина)».

## Канонічні компоненти сайту

### Форма заявки (2026-09-22)

- Один канонічний набір полів на всіх сторінках: Ім'я* (`name`), Компанія
  (`company`, необов'язкове), Телефон* (`phone`), Email (`email`),
  «Опишіть вантаж, маршрут і терміни» (`message`), згода (`consent`),
  кнопка «Надіслати».
- Приховані поля: `language`, `service`, `utm_source`, `utm_medium`,
  `utm_campaign`, `utm_content`, `utm_term`, `gclid`.
- Відправка — Formspree, обробник `[data-quote-form]` у `js/main.js`;
  подія `form_success` бере `service` прямо з поля форми, тому нове
  значення `service` не потребує змін у JS.
- Три допустимі розміщення: вбудована форма (головна, посадкові сторінки),
  `contacts.html?service=…` (динамічний заголовок через `ALLOWED_SERVICES`),
  CTA-кнопка з посиланням на `contacts.html?service=…` (сторінки послуг).
- Не додавати нових полів чи варіантів форми без окремого рішення.
- Джерело: сесія 22.09.2026, стандартизація форми посадкової сторінки.

### Навігація, дворівневе меню (2026-09-22)

- Підменю — лише CSS (`:hover` / `:focus-within` на desktop ≥ 1280px),
  на мобільному `.nav__sub` завжди розкрите в бургер-меню. JS керує лише
  атрибутом `data-open` бургера.
- Другий рівень — вкладений рядок під батьківським пунктом, не бокове
  flyout-меню (його легко «загубити» мишею — відхилено власником).
- Відкриття першого рівня — дочірній селектор `.nav__item:hover > .nav__sub`,
  щоб не розкривати вкладене підменю передчасно.
- Джерело: сесія 22.09.2026.

## Пастки

### CSS: однакова специфічність + порядок у файлі (2026-09-22)

- Правило з `@media` нижче у файлі тихо перебиває базове правило з тією ж
  специфічністю (напр. `.nav a` проти `.nav__sub--nested a`, обидва 0,1,1).
- Рішення: підвищувати специфічність батьківським класом
  (`.nav .nav__sub--nested a`), а не `!important`.
- Діагностика: пройти `document.styleSheets` і вивести всі правила, де
  `el.matches(rule.selectorText)`, у порядку файлу.
- `.nav ul { padding: 0 }` перебиває `.nav__sub { padding-left }` —
  для відступів підменю використовувати `.nav .nav__sub`.

### Кеш CSS під час перевірки (2026-09-22)

- Браузер часто показує стару версію `style.css` навіть після
  перезавантаження. Перед висновком «не працює» — додати до посилання на
  стилі `?v=<час>` (через DevTools / JS) або Cmd+Shift+R.

### Google Sheets: локаль таблиці (2026-09-22)

- Таблиці Sibway в українській локалі: у формулах через API розділювач
  аргументів «;», десятковий «,». Формули з «,» дають `#ERROR!`.

### Google Workspace API (2026-09-22)

- Drive API у GCP-проєкті вимкнений — працювати за відомими ID файлів
  (див. документ `claude/google-workspace-access.md` у проєкті Claude).

### Git у Cowork (2026-09-22)

- VM Cowork не може видаляти файли в підключеній папці без дозволу — git
  лишає `.git/index.lock` / `maintenance.lock`, і наступні git-операції
  падають. Потрібен дозвіл на видалення в папці репозиторію; видаляти лише
  lock-файли.
- Push / PR / merge — токен лише з файлу `~/.config/sibway-gh/token`,
  ніколи через чат або буфер обміну.

### DNS: wildcard (2026-09-22)

- У DNS є `*.sibway.com.ua` → сервер хостингу: будь-який неіснуючий
  піддомен відкриває заглушку Cityhost. Видалення конкретного піддомену не
  робить його «нерезолвним». Рішення лишити wildcard — T-001.

### Legacy на production (2026-09-22)

- На хостингу лишились файли старого сайту, включно з робочим
  `contact_form.php`, який відповідає «запит надіслано» навіть на GET.
  Не відкривати цю адресу під час перевірок — це може відправити порожній
  лист. Деталі й хвилі прибирання — `docs/LEGACY_CLEANUP_AUDIT.md`.

### Ефект «reveal» у скріншотах і перевірці контрасту (2026-09-22)

- Блоки `.reveal` мають `opacity:0`, доки JS не додасть `is-visible`.
  На скріншотах повної сторінки (headless) вони виглядають «вицвілими» —
  це не баг верстки; для перевірки контрасту вимикати анімації й
  прокручувати сторінку.

### Карти: Крим у world-atlas / Natural Earth (2026-09-23)

- У пакеті `world-atlas` (Natural Earth) Крим входить до геометрії Росії.
  Для будь-яких карт Sibway переносити полігон Криму до України —
  генератор `technical/tools/route-map/` робить це автоматично.

### Тексти: переноси й заборонені фрази (2026-09-23)

- Автоматичні переноси слів (`hyphens: auto`) не використовувати — рішення
  власника.
- Не використовувати фрази «Ми підбираємо транспорт через мережу
  партнерів-перевізників під конкретний маршрут і параметри партії. У процесі
  тримаємо зв'язок із клієнтом…» та «Ми не працюємо з приватними посилками,
  особистими речами або сценаріями, що не мають B2B-логістичного характеру»
  (і їхні EN/PL відповідники) — рішення власника.

### Меню: невидимий вкладений список ловить наведення (2026-09-23)

- Вкладений список (`.nav__sub--nested`) не повинен мати `visibility: visible`:
  всередині прихованого `.nav__sub` він лишається невидимим (opacity), але
  ловить наведення мишки — меню «Послуги» відкривалося від руху курсора під
  кнопкою. Правильно: `visibility: inherit`.
- Мобільне/планшетне меню (<1280px) — компактна панель праворуч під кнопкою
  меню (`width: min(22rem, 100vw - 2*gutter)`), не на всю ширину.

### Hero з картою: однакова висота в групах (2026-09-23)

- Класи `hero--map` (послуги, перевезення, імпорт, митне, склад, аудит) і
  `hero--map-wide` (про компанію, блог, контакти): фіксована мінімальна
  висота й фіксована висота зображення від 900px — карта стоїть у тій самій
  точці на всіх сторінках групи. Нова сторінка групи — додати клас.
- SVG-анімації в `<img>`: CSS-анімація з `transform` перезаписує атрибут
  `transform` елемента — позиціонувати зовнішньою `<g transform>`, а
  анімувати внутрішню `<g class>`.

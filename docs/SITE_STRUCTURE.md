## Спільні компоненти

Усі сторінки використовують спільні компоненти:

- **Header** — навігація, логотип, телефон, CTA
- **Footer** — навігація, контакти, юридична інформація
- **CtaBanner** — заклики до дії ("Отримати розрахунок", "Зателефонувати")
- **ServiceCard** — картки послуг
- **PageTransition** — анімації переходів (за потреби)

## Система анімацій

- Hero текст: fade-up на вході
- Hero зображення: fade-up з затримкою
- Картки: reveal on scroll зі stagger
- Hover: легкий lift + тінь
- Buttons: існуючі hover/focus стани
- Accessibility: `prefers-reduced-motion`

## Процес додавання нової сторінки

1. Створити макет у Stitch
2. Затвердити дизайн
3. Зберегти PNG + HTML у `design/approved/<page>/`
4. Додати README з Stitch Project ID, Screen ID, маршрутом
5. Оновити цей файл (`docs/SITE_STRUCTURE.md`)
6. Оновити `docs/SITE_MAP_UA.md`
7. Створити текст у `content/<page>.md`
8. Передати Antigravity Screen ID + маршрут
9. Реалізувати в існуючому React-проєкті
10. Перевірити локально
11. Зробити commit і push

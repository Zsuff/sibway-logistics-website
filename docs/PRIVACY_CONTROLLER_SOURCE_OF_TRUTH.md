## Обмеження використання

завдань без окремої потреби:

- IBAN або номер рахунку;
- назву або адресу банку;
- МФО, SWIFT-коди, кореспондентські банки чи кореспондентські рахунки;
- податкову групу, ставки податку або інші платіжні реквізити.

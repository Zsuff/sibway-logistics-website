# Логотип Sibway

У цій папці зберігаються затверджені файли логотипу для сайту.

## Бажані файли

- `sibway-logo-primary.svg` — основна кольорова версія
- `sibway-logo-primary.png` — PNG-версія основного логотипу
- `sibway-logo-white.svg` — біла версія для темного фону
- `sibway-logo-black.svg` — чорна або темно-синя версія для світлого фону

## Вимоги

- Основний формат для сайту — SVG.
- PNG використовуємо лише як запасний формат або для прев’ю.
- Не деформувати логотип, не змінювати його пропорції й кольори.

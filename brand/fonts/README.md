# Шрифти Sibway

## Брендові гарнітури

- Основний шрифт: TT Norms
- Додатковий шрифт: Gilroy

## Рекомендоване використання

| Елемент | Шрифт | Накреслення |
|---|---|---|
| H1, H2, ключові заголовки | TT Norms | Bold / Black Italic |
| H3, навігація, кнопки | TT Norms | Medium / Bold |
| Основний текст | Gilroy | Regular |
| Виділення в тексті | Gilroy | Bold / ExtraBold |
| Динамічні акценти | TT Norms | Black Italic / Heavy Italic |

## Ліцензія

Файли шрифтів додаються до репозиторію лише за наявності ліцензії,
що дозволяє їхнє вебвикористання та зберігання в цьому репозиторії.

Для сайту пріоритетний формат — WOFF2.
Формат WOFF можна додати як резервний для старіших браузерів.
Не завантажувати TTF або OTF у публічний репозиторій без підтверджених прав на розповсюдження.

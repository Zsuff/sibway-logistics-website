# Фірмовий патерн Sibway

Патерн Sibway складається з повторюваних стрілок/шевронів, які вказують напрям руху вперед.

## Призначення

Патерн використовуємо як допоміжний декоративний елемент:

- на великих фонових площинах;
- у CTA-секціях;
- у футері;
- на обкладинках, презентаціях і банерах;
- як стриманий акцент у Hero-секції.

## Правила

- Патерн не повинен погіршувати читабельність тексту.
- Не використовується як основний змістовий елемент.
- Блакитний акцентний елемент: `#189CD9`.
- Для нейтрального патерну використовуються сірі відтінки.
- Для темного фону допускається біла версія патерну.

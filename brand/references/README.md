# Візуальні референси бренду

У цій папці зберігаються вихідні матеріали, з яких формується дизайн-система Sibway.

## Очікувані файли

- `sibway-logobook.pdf` — повний логобук/брендбук.
- `logobook-colors.jpg` — сторінка з корпоративними кольорами.
- `logobook-fonts.jpg` — сторінка зі шрифтами.
- `logobook-pattern.jpg` — сторінка з фірмовим патерном.
- `logo-presentation-5.pdf` — варіант презентації логотипу.
- `logo-presentation-6.pdf` — варіант презентації логотипу.

## Примітка

Ці файли є довідковими матеріалами. Для верстки сайту використовуються підготовлені логотипи, патерни, кольорові токени та правила з `../DESIGN.md`.

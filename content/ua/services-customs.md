## Типові проблеми при митному оформленні

**Заголовок:** Типові проблеми при митному оформленні

### Проблема: неправильний код УКТЗЕД

**Наслідок:** затримка, штраф, перерахунок митних платежів

**Рішення:** наші брокери перевіряють код перед подачею декларації

### Проблема: відсутність сертифікатів

**Наслідок:** вантаж не пропускають через кордон

**Рішення:** допомагаємо отримати необхідні сертифікати заздалегідь

### Проблема: затримка на митному пості

**Наслідок:** простій транспорту, додаткові витрати

**Рішення:** супроводимо вантаж, оперативно вирішуємо питання на місці

## Приклад митного оформлення

**Заголовок:** Приклад митного оформлення

**Вантаж:** обладнання для виробництва, Німеччина → Україна

**Код УКТЗЕД:** 8462 99 90 00 (верстати для обробки металу)

**Митна вартість:** €45,000

**Митні платежі:**
- Митний збір: 0.2% = €90
- ПДВ: 20% = €9,000
- Акциз: 0% (не підакцизний товар)

**Термін оформлення:** 2 дні

**Документи:**
- Інвойс
- Пакувальний лист
- Договір купівлі-продажу
- Сертифікат відповідності
- Транспортна накладна (CMR)

**Результат:** вантаж митно оформлено без затримок, клієнт отримав повний пакет закриваючих документів.

## FAQ

**Заголовок:** Часті запитання

1. **Які документи потрібні для митного оформлення?**
   - Інвойс, пакувальний лист, договір, сертифікат походження (за потреби). Повний перелік надамо після аналізу вашого вантажу.

2. **Як довго триває митне оформлення?**
   - Стандартний термін — 1-3 дні для імпорту, 1-2 дні для експорту. Прискорене оформлення — 1 день.

3. **Чи допомагаєте з класифікацією товарів?**
   - Так, наші брокери визначають код УКТЗЕД та перевіряють його перед подачею декларації.

4. **Які митні платежі потрібно сплачувати?**
   - Митний збір, ПДВ, акциз (за потреби). Ставки залежать від коду УКТЗЕД та країни походження.

5. **Чи працюєте з фізичними особами?**
   - Так, супроводжуємо митне оформлення для фізичних осіб при імпорті товарів.

6. **Як відбувається оплата послуг?**
   - Оплата за рахунком на банківський рахунок. Можлива передоплата або післяплата за домовленістю.

# Sibway Logistics — документація проєкту

Цей репозиторій зберігає джерела вимог до нового багатомовного B2B-сайту Sibway Logistics: бренд, затверджений контент, макети, правила, рішення, задачі та технічні чеклісти.

## Пов'язані репозиторії

- Код сайту: https://github.com/Zsuff/sibway-website-
- Цей репозиторій: документація, контент і координація проєкту
- Маркетинг, SEO та лідогенерація (поточний активний проєкт): https://github.com/Zsuff/sibway-growth-ops
- Фінальний домен: https://sibway.com.ua
- Нова версія сайту вже запущена на домені; активна робота — маркетинг, SEO-просування та лідогенерація на цій версії

## Джерела правди

- HTML, CSS, JavaScript, публічні зображення та SEO-файли редагуються тільки в репозиторії коду (`sibway-website-`).
- Бренд, затверджені тексти, макети, правила, технічні рішення та план робіт ведуться тут.
- Маркетинг-опс — SEO-технічні завдання (GitHub Issues), `content-writing-rules.md`, ключові слова — ведуться в `sibway-growth-ops`; це активний робочий проєкт поточного етапу (просування й лідогенерація), а не застарілий чи неврахований репозиторій.
- Не копіюйте код або документи вручну між репозиторіями без фіксації зміни в Git.

## Структура

- `brand/` — логотипи, кольори, шрифти, дизайн-система та референси
- `content/ua/`, `content/en/`, `content/pl/` — тексти сторінок за мовами
- `design/approved/` — затверджені макети та візуальні рішення
- `docs/` — правила, рішення, беклог, workflow і журнал змін
- `technical/` — домен, хостинг, деплой, форми, SEO, QA та запуск

Код розробляється у Claude Code на Mac у локальній папці, синхронізованій з репозиторієм коду. Деталі: [`docs/PROJECT_WORKFLOW.md`](docs/PROJECT_WORKFLOW.md) та [`docs/RULES.md`](docs/RULES.md).

# Sibway Logistics Website

Сучасний веб-сайт для компанії Sibway Logistics — надійного партнера у міжнародній логістиці.

## 🚀 Технології

- **React 18** з TypeScript
- **Vite** — швидкий збірник
- **React Router** — навігація між сторінками
- **GitHub Pages** — хостинг та деплой

## 📦 Структура проекту

```
sibway-logistics-website/
├── src/
│   ├── components/     # React компоненти
│   ├── pages/          # Сторінки сайту
│   ├── styles/         # Глобальні стилі
│   ├── App.tsx         # Головний компонент
│   ├── main.tsx        # Точка входу
│   └── index.css       # Глобальні CSS стилі
├── content/            # Контент для сайту (ua, en, pl)
├── design/             # Дизайн-матеріали
├── docs/               # Документація
├── public/             # Статичні файли
└── index.html          # HTML шаблон
```

## 🛠️ Розробка

### Встановлення залежностей

```bash
npm install
```

### Запуск локального сервера

```bash
npm run dev
```

### Збірка для продакшену

```bash
npm run build
```

### Деплой на GitHub Pages

```bash
npm run deploy
```

## 📄 Сторінки

- **Головна** — презентація компанії, послуг, переваг
- **Про нас** — інформація про компанію, місія, цінності
- **Послуги** — перелік транспортних послуг
- **Транспорт** — транспортні послуги детально
- **Контакти** — контактна інформація та форма зворотного зв'язку

## 🌐 Локалізація

Контент доступний трьома мовами:
- 🇺🇦 Українська (`content/ua/`)
- 🇬🇧 Англійська (`content/en/`)
- 🇵🇱 Польська (`content/pl/`)

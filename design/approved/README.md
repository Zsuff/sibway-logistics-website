# Затверджені дизайн-макети

Ця папка містить резервні копії затверджених desktop-макетів сторінок Sibway Logistics, створених у Stitch.

## Призначення

- Зберігати візуальний еталон для реалізації та перевірки сторінок.
- Мати резервну копію, якщо макет або доступ до Stitch зміниться.
- Фіксувати HTML-експорт Stitch як довідковий матеріал, а не як production-код.

## Правила

- У `approved/` додаються лише погоджені макети.
- Для кожної сторінки зберігаються desktop screenshot (`*-desktop-vN.jpg`), HTML-експорт (`*-code-vN.html`) та README.
- Якщо дизайн суттєво оновлено після затвердження, створюється нова версія (`v2`, `v3`), а не перезаписується попередня.
- Production-версія сайту підтримується окремо в React + Vite + TypeScript. HTML Stitch є лише архівом/референсом.

## Поточні сторінки

- `homepage/` — головна сторінка, маршрут `/`.
- `services/` — сторінка послуг, маршрут `/services`.

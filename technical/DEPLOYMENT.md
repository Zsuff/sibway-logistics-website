# Деплой сайту

Цей файл описував деплой на етапі попереднього проєкту (докладніше — розділ
"Відкриті розбіжності" у `PROJECT_SOURCES_OF_TRUTH.md`, `sibway-growth-ops`).

staging/QA-піддомену (`preview.sibway.com.ua`) більше не існує, і процес
деплою давно змінився.

**Чинний release/deployment-процес — виключно [`docs/DEPLOYMENT.md`](../docs/DEPLOYMENT.md).**
Цей файл (`technical/DEPLOYMENT.md`) не оновлюється й лишається лише як
історичний покажчик; для будь-якої деплой-задачі читайте `docs/DEPLOYMENT.md`.

# Міграція старого сайту та 301-редиректи

## Мета

Безпечно замінити старий сайт на `https://sibway.com.ua`, зберегти релевантний пошуковий трафік і не залишити користувачів на 404.

## Правила

- Не запускати новий сайт, доки не створено резервну копію старого сайту.
- Кожний важливий старий URL має вести 301-редиректом на найближчу релевантну нову сторінку.
- Не перенаправляти масово всі старі сторінки на головну, якщо є відповідна сторінка послуги.
- Не створювати redirect chains: старий URL має за один крок вести на остаточний URL.

## Перед запуском

1. Вивантажити список старих URL зі sitemap, Google Search Console, CMS або сканування сайту.
2. Заповнити таблицю відповідностей.
3. Узгодити спосіб налаштування редиректів із хостингом: `.htaccess`, Nginx, панель хостингу або CMS.
4. Перевірити 301 на staging або після контрольованого запуску.
5. Зберегти таблицю як частину документації проєкту.

## Після запуску

- Перевірити 20–30 пріоритетних старих URL вручну.
- Перевірити 404 і Indexing у Google Search Console.
- Не прибирати редиректи щонайменше 12 місяців без окремого SEO-рішення.
